# Product Sense

GenUI is a prototype for exploring generative UI states and transitions. The product goal is fast, inspectable iteration on how UI can morph between compact states, lists, cards, and AI-driven flow surfaces.

## Audiences

- Designers tuning interactive UI scenarios.
- Agents implementing UI behavior from repository docs.
- Developers validating AI/prototype visual parity.

## Product Principles

- Make state changes visible and understandable.
- Keep scenario content data-driven.
- Favor shared visual systems over one-off page effects.
- Preserve typed/click fallbacks for AI and voice interactions.
- Optimize for resumability: project intent must live in the repo, not in chat.
- Let humans prompt with only role and goal; agents should infer product scope from specs.
- Preserve non-target products unless integration is explicitly requested.
