# GenUI Tool Spec

## Product Role

GenUI Tool is the manual editor surface for composing and inspecting generative UI scenarios.

## Core Capabilities

- Create and edit scenarios.
- Configure stages, components, typography, list items, images, and selected states.
- Persist browser-side scenarios and settings.
- Preview shape and stage transitions without requiring AI provider calls.
- Tune scenario-local content while preserving shared stage definitions.

## Related Products

- AI-driven flows belong in `ai-mode.md`.
- Bubble app-cluster home behavior belongs in `bubble-home.md`.
- Celestial visual tuning belongs in `celestial-visual-tool.md`.

## Non-Goals

- Production authentication.
- Multi-user persistence.
- Full backend database.
- Framework migration.
- Owning AI home behavior or bubble-home integration.
